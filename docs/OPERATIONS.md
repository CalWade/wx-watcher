# 日常运行、恢复、升级与卸载

## 日常使用

保持 Mac 微信登录、DSH 开启，确认当前账号与选定会话不变。
打开应用后检查概览；开始监控后，新消息自动进入持久化任务。
同事主要在飞书处理建议，调整配置、业务资料、费用和失败任务时回到本地应用。

关闭主窗口可在菜单栏继续运行。退出应用停止它拥有的后台进程。
「暂停监控」停止采集和回复 worker，不删除已保存的任务或密钥。
配置修改先暂停，再保存并重新启动，避免任务中途混用账号或目标群。

## 登录时启动

在应用「运行诊断」中可开启/关闭登录启动。源码或无图形环境可安装用户级 LaunchAgent：

```sh
uv run notebridge service install
uv run notebridge service status
uv run notebridge service uninstall
```

应用包安装后，下次登录在菜单栏启动原生应用，不主动弹出主窗口；源码环境启动本地后台。需要自动监控时，同时在应用里开启「打开本应用后自动恢复监控」。
用户级启动不需要把整个服务以 root 运行。系统可能显示后台项目通知。
安装后移动源码/虚拟环境会使旧入口失效，应先卸载旧入口再使用新路径安装。

## 任务状态

| 状态 | 含义和处理 |
| --- | --- |
| queued / inference | 已持久化并等待或正在调用模型 |
| draft | 有效建议，仅保存本地，或尚待发送 |
| sent | 飞书返回成功，记录了消息 ID |
| skipped | 系统通知、无有效诉求等，不投递 |
| needs_review | 模型失败、中断或 JSON 无效；检查原 DSH 会话 |
| delivery_review | 发送结果不明确；先核对飞书，再处理 |
| budget_review | 达到配置的每日调用上限 |

在「回复建议」中先暂停监控，再选择重新生成、忽略，或核对已投递。
重新生成使用新的模型任务 ID，保留原任务记录；会产生新的用量。
投递不明的任务只有明确确认未送达后才允许重新安排，不能直接自动重试。

重启复用任务 ID 查询原结果。模型或投递中断不能一律重新调用。
服务范围绑定账号与会话指纹；切换账号/会话使用独立任务目录。

## 断网、休眠和重启

暂时网络故障保留任务。监督器先等待读取服务就绪，再重启回复进程，避免依赖未恢复时消耗重试次数。休眠期间本机无法实时收消息，唤醒后读取已同步的本地新增数据。
系统需重新确认微信登录或 Keychain 访问时，先处理真实权限问题，不默认重新取钥。
DSH 重启中途的调用可能已消耗用量但未保存结果，需要查原会话。
进程被强杀或掉电后检查未完成的捕获恢复和投递任务。

十秒属于目标延迟，取决于消息落库、合并等待、队列、模型和飞书。
分别测量这些阶段；不能用一次文件传输助手测试承诺所有客户群实时性。

## 资料与用量

业务资料支持 UTF-8 Markdown/TXT，单文件最多 1 MB、总计最多 4 MB。
系统在本地按问题选取有限相关段落；资料不是模型可执行指令。
修改资料后新任务使用新内容，已提交模型的提示保持原样便于追溯。
每日调用上限按 UTC 日期、本系统已提交任务计算，非供应商金额账单硬上限。
cost-meter 金额为估算，未知价格不应解释为免费。

## 私有数据与备份

默认应用目录在 `~/Library/Application Support/NoteBridge`。
Keychain 保存密钥和 App Secret；配置和任务保存在各账号/会话私有子目录。
备份时先暂停服务，保存配置、任务 SQLite、必要资料，以及凭据的加密备份。
不要直接复制正在写入的 SQLite 单个文件而漏掉 WAL；使用一致备份。
DSH sessions 和 cost-meter ledger 由 DSH 自己保管，需要独立备份。

## 保留期与游标恢复

「业务资料」可设置保留天数，默认 30 天；0 表示不自动清理。读取事件按本机收到时间清理，
已完成、跳过、忽略或已重新安排的任务按更新时间清理；待处理任务保留供人工核对。
清理只处理本应用自己的副本，不修改微信源库。SQLite 空闲页、旧备份及系统快照并不等同于安全擦除。
DSH 会话、桥接任务文件和 cost-meter 账本由 DSH 管理，不受此设置控制。

消费游标超过保留期时，接口明确返回 HTTP 410，worker 停在错误状态。先暂停监控，
在「运行诊断」点击「确认缺口并修复游标」。确认后记录被跳过的游标范围，从当前最新位置继续。
此操作不能补回已删除的事件，不会自动清除尚未完成的任务。

## 升级

1. 暂停服务，记录版本，备份私有配置、任务及凭据。
2. 安装新应用或按锁文件更新源码依赖。
3. 运行环境、密钥和数据读取检查，通常复用原密钥。
4. 更新 DSH 桥接，测试一次模型/费用和一次飞书投递。
5. 恢复监控，核对游标与历史任务没有重复。

不同签名/代码身份的原生凭据工具可能需要系统重新确认 Keychain 访问。
正式分发应保持稳定的 Developer ID 与应用身份；不可为免弹窗放宽到任意应用读取密钥。

## 卸载

先暂停并退出应用，移除用户级启动配置，再移除应用。
只删除 DSH patch 中本项目的 `notebridge` 条目，保留其他模型和插件配置。
是否删除任务、加密备份、Keychain 凭据由用户决定，默认保留成果。
未完成客户端恢复的官方备份不得直接清理。


## 微信切换了另一个账号

先看页面顶部的「微信当前登录」和「本项目正在使用」。当前账号无密钥时选择连接当前账号，
已有密钥时选择验证并切换；旧凭据会保留。切换本项目后要重新选择微信会话，自动投递与自动恢复监控默认关闭。
运行中检测到账号变化会暂停监控，不能继续依靠旧账号的已保存状态运行。
完整步骤见 [新机指南的账号切换部分](FIRST_RUN.md#7-已有配置但微信换了另一个账号)。
